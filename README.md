### **What it does**
Skilling Loot Tracker runs silently while you skill and automatically logs every item you obtain from **Fishing, Mining, and Woodcutting**. No setup, no spreadsheets. Just real loot data, GP/hr, and session stats built straight into RuneLite.

### **Core Features**

| Feature | Description |
| --- | --- |
| **Automatic Loot Detection** | Tracks all resources from Fishing, Mining, and Woodcutting. Compatible with barehanded, crystal tools, 3-tick, and tick manipulation. |
| **Session Management** | Start, reset, and view stats from the side panel. Tracks active skilling time only. |
| **Value & Profit Tracking** | Live Grand Exchange prices for total haul value. Calculates real GP/hr based on time spent skilling. |
| **Per-Skill Breakdown** | See item counts, value subtotals, and drop rates per skill. Know exactly how much coal, runite ore, magic logs, or anglerfish you’ve earned. |

### **UI & Quality of Life**

- **Dedicated Side Panel**: Lives with your other RuneLite plugins. Expandable sections for each skill with quick-reset and export buttons.
- **In-Game Overlay**: Optional minimal overlay showing session time, total value, and GP/hr. Toggle on or off.
- **Fully Configurable**: Enable/disable individual skills. Lightweight and performance friendly.
- **Data Persistence**: Session data saved locally between client restarts.

### **Technical Details**
- **Built for**: RuneLite Plugin Hub
- **License**: MIT — open source and contributions welcome on GitHub
- **Privacy**: All data stored locally. Nothing sent externally.

**Ideal For**  
Players grinding 99s, Ironmen tracking supplies, and efficiency scapers who want accurate profit data without running 3rd party tools.
