# Skilling Loot Tracker
A RuneLite plugin for tracking resources and profit from gathering skills

What it does
Skilling Loot Tracker automatically logs every item you obtain from Fishing, Mining, and Woodcutting. It runs in the background while you skill and builds a detailed breakdown of your loot, and GP/hr without manual input.

Core Features

Automatic Loot Detection
Tracks all resources from Fishing, Mining, and Woodcutting. Works with barehanded methods, crystal tools, 3-tick, and tick manipulation.
Session Management
Reset sessions from the side panel. View current session stats.
Value & Profit Tracking
Live GE price integration for total haul value. Calculates GP/hr based on active skilling time.
Per-Skill Breakdown
Organizes loot by skill with item counts, value subtotals, and drop frequency. See exactly how much coal, runite ore, magic logs, or anglerfish you’ve earned per session.
UI & Quality of Life

Dedicated Side Panel
Icon sits with other RuneLite panels. Expandable sections for each skill. Quick-reset and export buttons.
Overlay Options
Optional in-game overlay showing session time, total value, and GP/hr. Minimal mode available.
Toggle individual skills on or off. Lightweight on performance.
Storage: Session data saved locally between client restarts.
Open Source: MIT license. Contributions welcome on GitHub.

Ideal For
Players grinding 99s, Ironmen tracking supplies, and efficiency scapers who want accurate profit data from gathering skills without running 3rd party spreadsheets.
