# Skilling Loot Tracker

A RuneLite plugin that tracks skilling loot gained from:
- Fishing
- Mining
- Woodcutting

Features:
- Loot tracking panel
- Session value tracking
- Per-skill loot categorization

Built for RuneLite Plugin Hub.
